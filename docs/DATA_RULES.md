# Data Rules

- 保存済みデータと既存APIの後方互換性を維持する。
- 既存フィールドの削除・改名・型変更を無断で行わない。
- フィールド追加時も旧データを読み込めるようにする。
- D1等のDB構造変更はmigrationとして残す。
- LocalStorage、DB、Sheets、Drive等の実データを仮データで上書きしない。
- データ削除を伴う変更は対象と条件を明示し、安全側で停止できるようにする。
- API入出力と保存形式が変わった場合、各アプリの `docs/DATA_CONTRACT.md` を同じ変更単位で更新する。
- 秘密情報、APIキー、トークン、個人情報をリポジトリへ保存しない。
