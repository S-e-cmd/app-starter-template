# Batch Completion Choices

既存アプリ非破壊整備モードでは、各バッチ終了時に整備必要度・理由・推奨を示したうえで、次の選択肢を必ず短い説明付きで提示します。

## 表示ルール

推奨する選択肢には `← 推奨` を付けます。

例:

```text
[今回は終了] ← 推奨 — 現在の整備必要度が低く、残りは任意改善中心
[続ける] — app.js 内部の保存処理だけを限定的に整理
[別の箇所を優先] — 気になる機能・UI・保存・公開周りなどを指定
```

## 選択肢の意味

### 今回は終了

現在状態、確認済み範囲、未確認範囲、残タスク、次回再開位置を `docs/PROJECT_STATUS.md` に残して終了します。

### 続ける

AIが `docs/PROJECT_STATUS.md` と現在の整備必要度から、次の安全なバッチを1つ選びます。表示時には、何を次に行う予定かを短く具体的に添えます。

### 別の箇所を優先

現在の自動候補ではなく、ユーザーが指定した箇所を次バッチ対象に切り替えます。表示時には `気になる機能・UI・保存・公開周りなどを指定` のように、何を指定すればよいか分かる説明を添えます。

ユーザーが対象を指定せずこの選択肢だけを選んだ場合は、対象箇所だけを確認します。勝手に別の整備対象を選びません。

## 禁止

- `[続ける]` などラベルだけを並べ、何が起きるか説明しない。
- 推奨理由を示さずに選択を求める。
- `別の箇所を優先` をAI側の別候補選択として扱う。
- 整備必要度が低いのに、継続を既定として誘導する。
